# TabPFN Benchmark



## Overview
This study is to determine how TabPFN’s predictive performance and robustness measures against Logistic Regression, XGBoost, LightGBM, CatBoost, Decision Tree, and Dummy (prior) across tabular classification datasets. All methods are ‘out of the box’ untuned.
Experiment 1: Increasing of Training Dataset Scarcity
Experiment 2: Increasing Nested Dataset Cell Missingness
Experiment 3: Class Imbalance
Across these experiments, the study will measure both absolute performance and deterioration relative to each method’s unstressed baseline.
